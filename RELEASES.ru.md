## 🚀 Инструкция по установке на Windows

### Способ 1: Установка в 1 клик (Рекомендуется)
1. Скачайте архив **NetWard-v0.1.0-Windows-x64.zip**.
2. Распакуйте архив в любую удобную папку.
3. Запустите файл **`install.cmd`** (двойным кликом).
4. Программа автоматически установится в вашу пользовательскую директорию `%LOCALAPPDATA%\Programs\NetWard` и создаст ярлыки на **Рабочем столе** и в меню **Пуск**.
5. Права администратора **не требуются**.

### Способ 2: Портативный запуск (Portable)
1. Распакуйте архив.
2. Запустите файл **`NetWard.App.exe`**.
3. Программа готова к работе без установки в систему.

## 🔍 Проверка целостности (SHA-256)

Перед запуском вы можете убедиться в подлинности файла с помощью встроенной команды PowerShell:

```powershell
Get-FileHash -Algorithm SHA256 NetWard-v0.1.0-Windows-x64.zip
```
Хэш должен точно совпадать с:
`9B5098D474277AE00572B67742506D45DE437ADBAD48E3870BB588965D167E4A`

## ℹ️ Примечание о Windows SmartScreen

Так как проект является независимым открытым ПО и не использует дорогостоящий коммерческий сертификат подписи EV Code Signing ($400/год), Windows SmartScreen при первом запуске может показать синее информационное окно («Система Windows защитила ваш компьютер»).
1. Нажмите **«Подробнее» (More info)**.
2. Нажмите **«Выполнить в любом случае» (Run anyway)**.
3. Программа полностью безопасна, не содержит скрытых служб, не требует root/admin прав и имеет открытый исходный код.
