## Reporting a Vulnerability

The NetWard security team takes vulnerabilities seriously.

If you discover a security vulnerability (such as a local privilege escalation, improper socket manipulation, or potential memory safety issue), **please DO NOT create a public GitHub issue**.

Instead, report it responsibly via:
1. **GitHub Private Vulnerability Advisory:** Go to the "Security" tab of the repository and click "Report a vulnerability".
2. **Email:** Send encrypted or plain details to `security@rovel.org`.

### What to Include:
- Description of the vulnerability.
- Steps to reproduce or proof-of-concept code.
- Affected OS platform and NetWard version.

### Response SLA:
- **Acknowledgement:** Within 48 hours.
- **Triage & Remediation Plan:** Within 7 business days.
- **Public Disclosure:** Following an agreed grace period after a patch release has been published.
